## 컨셉

물과 무지개를 모티프로 한 검사. 겉으로는 나른하고 귀찮아하지만 실력은 천재인 캐릭터임. 발도술은 귀찮아서 최단·최소 동작만 하다 보니 생긴 결과라는 설정을 붙임.

## 관통 판타지 — 빨리 퇴근하는 귀차니즘

킷 전체를 한 줄로 묶는 판타지를 먼저 정함. 캔슬을 잘하면 게이지가 빨리 차고, 강화 공격을 빨리 쓰고, 궁극기를 빨리 켜고, 빨리 썰고, 빨리 퇴근함. 선택지를 늘리는 대신 메커니즘을 일렬로 엮어 **잘할수록 가속되는 구조**로 설계함.

## 캔슬 설계

캔슬에는 두 가지 의도가 있었음.

- **연출:** 졸고 있는 캐릭터를 플레이어 입력으로 깨우는 것
- **메커니즘:** 원작 소드마스터의 후딜 캔슬을 더 쉽게 쓸 수 있게 주는 것

평타 리듬은 단타, 단타, 다단히트로 잡음. 무겁게 두 번 눌러 담다가 마지막에 확 푸는 리듬임. 캔슬 입력 창은 3타 막타 판정이 끝나는 순간의 5~6프레임이고, 그보다 일찍 누르면 남은 히트를 잃음. 그래서 캔슬해도 남은 히트 피해가 사라지지 않게 보존하는 사양을 따로 요청함.

## 연출로 페이즈 구분

궁극기 전후를 발도 동작의 유무로 나눔. 평소엔 뽑고, 베고, 거두는 과정을 다 보여주고, 궁극기 뒤에는 뽑는 동작을 생략하고 베는 결과만 보여줌. 나른함과 예리함의 대비를 모션으로 만들려 한 것임.

## 회고 — 의도가 전달되지 않은 지점

- **나른함이 사라짐.** 하품이나 조는 연출은 "전투 중에 왜 하품하냐"는 이유로 빠짐. 대신 멋이라도 살리려고 넣은 이동 참격, 백덤블링, 돌진 때문에 성격을 모르고 전투만 본 사람은 오히려 명랑한 캐릭터로 읽음.
- **캔슬의 재미가 약했음.** 캔슬 타이밍이 길어지고, 액션이 짧아 끊을 후딜 자체가 적었고, 캔슬한 뒤에 이어갈 이유도 약했음.
